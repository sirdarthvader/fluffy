# Example App

This app is the permanent Phase 1 fixture for Fluffy.

It should stay small until the framework is stable:

- one `src/pages/index.tsx` route
- no styling framework
- no data loading
- no production-only assumptions

Run it from the repository root:

```sh
pnpm dev:example
```

Smoke-test it from the repository root:

```sh
pnpm smoke:example
```
