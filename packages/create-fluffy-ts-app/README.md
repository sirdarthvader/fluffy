# @fluffy-ts/create-app (Scaffolding)

- Bootstraps new projects
- Possible structure for now

```sh
pnpm dlx @fluffy-ts/create-app@latest my-fluffy-ts-app
```

```
create-app/
├── templates/
│   └── basic/       # Starter template
│       ├── src/
│       ├── public/
│       └── package.json
└── index.js         # CLI logic
```
